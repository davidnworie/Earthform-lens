# Earthform Lens River Lab — starter
Copy analysis.html and analysis.js into the root of the existing GitHub Pages repository. Visit /Earthform-lens/analysis.html. Add a link to this page from the existing index.html if desired. No build step. Leaflet and basemap tiles require network access.

## Input
Upload WGS84 GeoJSON FeatureCollections independently for A and B. Main channel: LineString, properties.role = main, coordinates ordered upstream to downstream, optional third coordinate elevation in metres. Optional roles: catchment and delta (Polygon/MultiPolygon), stream and distributary (LineString, complete networks without overlaps), channel_width, floodplain_width, valley_width (measured cross sections, paired channel/valley via transect_id), migration (measured displacement line, properties.years), erosion and accretion (preclassified polygons). Nonoverlapping polygons required. Supply the same data resolution and measurement methods for comparisons. This tool does not independently delineate these features. Example is synthetic, not real river data.

## Implemented
Two independent maps, uploaded geometry, distance, endpoint sinuosity, mean absolute turning curvature, net gradient, channel relief, profile overlay, catchment and delta area, drainage density from supplied stream lines, transect widths, paired confinement, distributary length, migration rates and supplied erosion/accretion areas; CSV export. Spherical area and distance approximations; not survey grade. No automated global river retrieval, elevation download, watershed delineation, Strahler ordering, knickpoint detection, hypsometry, wavelength, satellite time series or sediment routing classification yet. These need additional network/raster processing and scientific validation. No live deployment or browser testing performed.
